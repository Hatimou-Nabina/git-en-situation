# Code de conduite

git-en-situation existe parce que personne ne connaît tout Git, pas même après dix ans. Ici, ne pas savoir est le point de départ, jamais un motif de moquerie.

## Ce qu'on attend

- **Bienveillance envers qui apprend.** Une question « de débutant » est une situation qui manque au site. On y répond, ou on ouvre une issue pour l'écrire.
- **Désaccord sur les idées, jamais sur les personnes.** On discute d'une commande, d'une formulation, d'un choix éditorial. On ne commente pas le niveau ou l'expérience de quelqu'un.
- **Exactitude avant tout.** Si tu n'es pas sûr, dis-le. Une correction est un cadeau, pas une attaque, et on la reçoit comme telle.
- **Respect du temps des autres.** Issues et pull requests claires, qui suivent les gabarits.

## Ce qui n'a pas sa place

Insultes, harcèlement, remarques discriminatoires (origine, genre, orientation, religion, handicap, âge, niveau d'études ou d'expérience), publication d'informations privées, et toute conduite qu'une personne raisonnable jugerait déplacée dans un cadre professionnel.

## En cas de problème

Signale-le au mainteneur par message privé sur GitHub (@Hatimou-Nabina) ou dans une issue si tu préfères que ce soit public. Chaque signalement est lu. Selon la gravité : rappel, avertissement, suppression du contenu, exclusion temporaire ou définitive du projet.

Ce code s'applique dans tous les espaces du projet : dépôt, issues, pull requests, discussions, et partout où quelqu'un représente le projet.

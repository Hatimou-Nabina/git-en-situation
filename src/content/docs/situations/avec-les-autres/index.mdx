Seul, Git est simple. Les situations de ce thème arrivent quand le travail des autres rencontre le tien : `main` a avancé pendant que tu travaillais, une fusion a eu lieu sur GitHub sans toi, tu as deux comptes ou deux machines. Chaque page dit ce qui se synchronise, ce qui ne se synchronise pas, et dans quel ordre agir.

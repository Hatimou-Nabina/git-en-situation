## The outputs shown are real

No output is written by hand. Every situation has a versioned script that replays the scenario in throwaway repositories and prints each command followed by its output. The page copies that result, with the Git version and the date it was run. If your output differs, that's a mistake on the site, and [we want to know](https://github.com/Hatimou-Nabina/git-en-situation/issues/new?template=signaler-une-erreur.yml). Details in [How to read a situation](/en/situations/comment-lire/).

</section>

Git compte plus de 150 commandes. Une quarantaine servent vraiment, et pour chacune, trois ou quatre options couvrent l'essentiel. Cette section s'en tient là. Pour le reste, la documentation officielle (`git help <commande>`) fait référence, et chaque fiche y renvoie.

Une fiche n'est pas une copie du manuel. Elle répond à trois questions : à quoi sert cette commande, quelles options valent la peine d'être connues, et dans quelles situations de ce site on la rencontre.

Commandes prévues, par usage :

- **Tous les jours** : `status`, `add`, `commit`, `switch`, `branch`, `log`, `diff`, `fetch`, `pull`, `push`, `merge`, `rebase`, `stash`.
- **Pour s'y retrouver** : `show`, `blame`, `grep`, `reflog`, `rev-list`, `merge-base`, `describe`.
- **Pour réparer** : `restore`, `reset`, `revert`, `cherry-pick`, `commit --amend`, `rebase -i`.
- **Pour configurer** : `config`, `remote`, `tag`, `clean`, `worktree`, `bisect`.
- **GitHub, en ligne de commande** : `gh pr`, `gh issue`, `gh repo`, signalés comme spécifiques à GitHub.

Tu veux écrire l'une de ces fiches ? Le gabarit est dans le `CONTRIBUTING.md` du dépôt.

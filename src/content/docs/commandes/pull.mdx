## À quoi ça sert

`git pull` enchaîne deux commandes : [`git fetch`](/commandes/fetch/), qui récupère, puis `git merge` ou `git rebase`, qui intègre dans ta branche ce que sa branche du serveur a reçu. Quand tu n'as rien commité en local, c'est une simple avance rapide. Quand les deux côtés ont avancé, Git te demande de choisir comment réconcilier, et c'est là que tout se joue. Le manuel complet : `git help pull`.

## Les formes qui servent

**`git pull`**, le cas simple : rien en local, le serveur a avancé. La branche avance en ligne droite, « Fast-forward ».

```console
$ git pull
From github.com:equipe/projet
   d0a0b32..4bb498d  main       -> origin/main
Updating d0a0b32..4bb498d
Fast-forward
 contact.js | 1 +
 1 file changed, 1 insertion(+)
 create mode 100644 contact.js
```

**Quand les deux côtés ont avancé**, `git pull` sans réglage s'arrête et explique les trois choix. Le `fetch` a eu lieu, l'intégration non.

```console
$ git pull
From github.com:equipe/projet
   4bb498d..1ad2b74  main       -> origin/main
hint: You have divergent branches and need to specify how to reconcile them.
hint: You can do so by running one of the following commands sometime before
hint: your next pull:
hint:
hint:   git config pull.rebase false  # merge
hint:   git config pull.rebase true   # rebase
hint:   git config pull.ff only       # fast-forward only
hint:
hint: You can replace "git config" with "git config --global" to set a default
hint: preference for all repositories. You can also pass --rebase, --no-rebase,
hint: or --ff-only on the command line to override the configured default per
hint: invocation.
fatal: Need to specify how to reconcile divergent branches.
```

**`--ff-only`** refuse tout ce qui n'est pas une avance rapide : tu sais alors qu'il y a divergence, et tu choisis en connaissance de cause. **`--rebase`** rejoue tes commits par-dessus ceux du serveur, et l'historique reste en ligne droite.

```console
$ git pull --ff-only
hint: Diverging branches can't be fast-forwarded, you need to either:
hint:
hint: 	git merge --no-ff
hint:
hint: or:
hint:
hint: 	git rebase
hint:
hint: Disable this message with "git config set advice.diverging false"
fatal: Not possible to fast-forward, aborting.

$ git pull --rebase
Rebasing (1/1)Successfully rebased and updated refs/heads/main.

$ git log --oneline -3
1acd006 feat(recherche): ajoute la barre de recherche
1ad2b74 feat(export): ajoute l export CSV
4bb498d feat(contact): ajoute la page contact
```

**`pull.ff only`** une fois pour toutes : `git pull` ne fait plus que l'avance rapide, et tu passes `--rebase` quand il le faut. C'est le réglage de ce site.

```console
$ git config --global pull.ff only
```

**Sans branche de suivi**, `pull` ne sait pas quoi tirer : une branche créée en local n'a pas encore de correspondante sur le serveur.

```console
$ git switch -c feature/filtres
Switched to a new branch 'feature/filtres'

$ git pull
There is no tracking information for the current branch.
Please specify which branch you want to merge with.
See git-pull(1) for details.

    git pull <remote> <branch>

If you wish to set tracking information for this branch you can do so with:

    git branch --set-upstream-to=origin/<branch> feature/filtres

```

## Pièges

- **`git pull` par réflexe sur `main`**, avec un commit local oublié et `pull.rebase false` : un merge, et un commit « Merge branch 'main' of … » dont personne ne veut. `--ff-only` l'empêche : [Ma branche locale est en retard après une fusion sur GitHub](/situations/avec-les-autres/branche-locale-en-retard-apres-fusion/).
- **Merge ou rebase ?** Rebase pour tes branches à toi, merge quand la branche est partagée : [git pull me demande de choisir entre merge et rebase](/situations/quotidien/git-pull-merge-ou-rebase/).
- **Un `pull --rebase` qui s'arrête sur un conflit** laisse le rebase en cours, en « detached HEAD ». `git rebase --abort` ramène à l'état d'avant : [Un conflit pendant un merge ou un rebase](/situations/reparer/resoudre-un-conflit/).
- **`pull` tire la branche suivie, pas « le serveur ».** Sur `feature/x`, c'est `origin/feature/x` qui arrive, pas `main`. Pour intégrer `main` dans ta branche : [Mettre ma branche à jour avec main](/situations/avec-les-autres/mettre-ma-branche-a-jour-avec-main/).
- **Avec des modifications en cours**, `pull` peut refuser, « Your local changes would be overwritten » : commit ou `stash` d'abord.
